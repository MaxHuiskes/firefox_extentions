GitHub Gist sync (manual)

Sync only when you click the button (pull → push). No auto sync on save or popup open.

Setup (2 minutes)
  1. Open github.com/settings/tokens
  2. Generate new token (classic)
  3. Enable only the gist scope → Generate
  4. Paste token below → Save → Sync now
  5. On the other device: same token + same Gist ID → Sync now
